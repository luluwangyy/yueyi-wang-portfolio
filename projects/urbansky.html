UrbanSky

Overview

UrbanSky turns a growing collection of 1,067+ HDR lighting environments into an interactive 360° web explorer, helping researchers browse the dataset by location, time, and weather.

My Role

I worked as the Web Engineer, implementing the provided design within an existing Node.js architecture and building a responsive data-driven interface that can automatically accommodate new environments as the dataset continues to grow.

Walkthrough

Key Engineering Moments

01

Turning raw captures into usable 360° panoramas

Before the environments could be explored in the browser, the source images had to be stitched into consistent panoramic assets.

I used PTGui to process and stitch the HDR captures into 360° panoramas, checking alignment, seams, and orientation before bringing them into the web experience.

The browser experience depended on more than the interface—it also depended on preparing clean, consistent panoramic assets upstream.

02

Making a large dataset explorable through the map

With 1,067+ environments, a simple list or gallery would quickly become hard to navigate.

I built the map as a primary exploration layer so researchers could browse captures spatially, understand where each environment came from, and jump directly into a panorama from its location.

The map turns a large dataset from something you search through into something you can explore.

Each map point is connected to its corresponding panorama and metadata, so location becomes part of the browsing experience rather than just another field in a table.

As the dataset grows, new entries can appear within the same map-based structure without changing the overall interaction model.

03

Dynamic dataset loading

The current dataset contains 1,067 environments, but the interface is not designed around that number.

Whether the dataset contains 1,067 environments or many more, new entries can flow into the same responsive structure without requiring new pages or layout changes.

New panorama and metadata entries are loaded through the same data structure and rendered through reusable components, so the browsing, filtering, and 360° viewing experience continues to work as the collection expands.

New environment → Dataset → Reusable components → Existing responsive interface

Outcome

1,067+ current HDR environments—and growing
Dynamic new entries automatically fit the existing interface
360° interactive exploration
Full-stack React + Node.js implementation
