SketchTrace

Helping people understand the code AI can generate in seconds.

Type Product Design · Design Engineering · AI
Role Product Designer & Full-Stack Engineer
Affiliation Design Tool Lab, Barnard College, Columbia University
Duration 2024–2025
Platform Responsive Web Application
Scope Product Strategy · UX/UI · React · Express · AI Integration · Testing & Deployment

AI can now turn an idea into working code almost instantly. But generating code and understanding it are two different things.

SketchTrace is an interactive learning workspace that connects source code, live behavior, and clickable system maps — helping creative coders inspect how unfamiliar programs actually work.

View Live Demo View GitHub

The system map turns unfamiliar code into something users can navigate: selecting a concept reveals the exact source code responsible for it.

The Problem

AI has dramatically lowered the barrier to writing code. A user can describe an interaction, press enter, and receive hundreds of lines of working JavaScript within seconds. But that convenience creates another problem:

Being able to generate code does not mean being able to understand it.

For creative coders especially, unfamiliar programs may contain animation loops, interaction states, geometry, recursive functions, and rendering logic distributed across hundreds of lines. The visible result might be immediately understandable. The system behind it often is not.

Most AI coding tools optimize for:

Prompt → Generate → Run

I wanted to explore a different loop:

Generate → Inspect → Understand → Modify

SketchTrace helps users move between three representations of the same program:

Code → Behavior → Structure

Instead of replacing the learning process, AI becomes a way into it.

SketchTrace reorganizes the experience around understanding rather than generation. Users can inspect the source code, immediately see what it produces, and then use a structural map to understand how the major systems relate.

The three views stay visible together so users can continually move between implementation, behavior, and structure.

Read it → See it → Trace it

Rather than asking users to accept AI-generated code as a black box, SketchTrace gives them multiple ways to interrogate it.

Testing With Real Creative Code

Simple UI examples did not demonstrate why structural visualization mattered, so I created four more demanding creative-coding studies. These examples include animation loops, recursion, geometry, pointer interaction, responsive behavior, and parallel systems — they became both learning content and stress tests for the product.

  • Three.js Particle Terrain
  • Kinetic Typographic Grid
  • Recursive Wind Garden
  • Boid Constellation Simulation
01

Showing Complexity Without Recreating the Code

My first diagrams tried to represent almost every meaningful function and relationship. They were technically complete — but difficult to understand. I reduced each example to roughly 11–13 essential nodes, prioritizing major systems and dependencies rather than implementation detail.

Before

“Show everything.”

After

“Show enough to build a mental model.”

02

Connecting Explanation Back to the Real Code

AI can explain code in natural language, but explanations can become another abstraction users have to trust. I wanted every explanation in SketchTrace to remain connected to the actual program.

Each system-map node therefore contains an exact source range. Selecting a node automatically:

  • opens the relevant JavaScript
  • highlights the corresponding source
  • scrolls it into view
  • focuses the editor

The user never has to choose between an AI explanation and the code itself. The explanation becomes a doorway back into the source.

03

Using AI as a Teacher, Not an Autopilot

Many AI coding products use the model primarily to produce more code. In SketchTrace, I intentionally gave AI a different responsibility: interpretation.

When users provide unfamiliar or modified code, AI identifies its important systems and relationships. That interpretation is then validated and transformed into an interactive structural map.

User Code
↓
AI Interpretation
↓
Validation
↓
Interactive System Map
↓
Source Code

The goal is not to hide implementation behind AI. It is to use AI to create an entry point into implementation.

The Final Experience

Users can now:

  • Load a creative-coding example or paste their own code
  • Run it immediately in a live preview
  • Generate a concise structural map
  • Click nodes to navigate directly to source code
  • Pan, zoom, and resize the workspace while exploring

Resizable panels allow users to emphasize whichever representation — code, behavior, or structure — is most useful at that moment.
